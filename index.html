2 Cara termudah untuk menerbitkan website portofolio ini secara online

1 Metode GitHub (Sangat Disarankan & Otomatis)

  1. Buat repository baru di GitHub.com (misal: drone-portfolio).
  2. Upload seluruh file di folder ini ke repository GitHub Anda.
  3. Buka Vercel.com, login dengan akun GitHub Anda.
  4. Klik tombol "Add New..." → "Project", lalu pilih repository tadi.
  5. Klik "Deploy". Dalam 10 detik, website Anda langsung online dengan domain gratis seperti nama-anda.vercel.app!

2 Menyimpan File Foto/Video Permanen di Server

Jika Anda ingin video dan foto pribadi Anda selalu tampil permanen untuk siapa saja yang membuka web di Vercel:

  • Letakkan file foto Anda di folder assets/images/.
  • Letakkan file video Anda di folder assets/videos/.
  • Buka app.js, dan tambahkan nama file Anda ke dalam daftar array INITIAL_MEDIA.
